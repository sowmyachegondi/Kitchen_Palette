# Kitchen Palette

Kitchen Palette is a recipe web application designed and developed to help users explore different food categories such as breakfast, lunch, snacks, sweets, chutneys, and beverages.

The user interface was first designed and practiced using **Figma**, and then implemented using **HTML, CSS, and JavaScript**.



## UI Design

The complete user interface was initially designed in **Figma** to practice UI/UX design principles before development.

- Layout planning
- Color palette selection
- Component design
- User experience flow



## Features

- User Login and Signup pages
- Recipe categories
  - Breakfast
  - Lunch/Dinner
  - Snacks
  - Sweets
  - Chutneys
  - Beverages
- Recipe search functionality
- Add recipes to favourites
- View favourites page
- Responsive design
- Modern card-based UI
